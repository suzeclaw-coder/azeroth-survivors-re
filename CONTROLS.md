# Controls

**Azeroth Survivors** — top-down, one hand on WASD, the other on the wheel.

| When | Key / Input | Action |
|---|---|---|
| Menu | Click a race, gender, class and zone | make your pick (**Randomize** rolls one) |
| Menu | **Enter** (or **Enter World**) | start the run; the world travels to the zone picked |
| Playing | **W / S / A / D** or **arrow keys** | move the hero (locked camera: the hero faces the cursor, backpedals and strafes) |
| Playing | **Space** | jump (or unleash Class Ultimate when meter reaches 100%) |
| Playing | **Left Shift** | dash forward (12 yd surge, 0.25s i-frame, 3s cd) |
| Playing | **F** (from level 5) | your class's movement spell: Blink, Charge… aim at the cursor |
| Playing | **C** | unlock / lock the camera |
| Any | **G** | toggle the picture polish (`?grade=0` starts it off) |
| Playing | **mouse wheel** | zoom, from over the shoulder out to 70 yd |
| Playing | **drag** (camera unlocked) | swing and tilt the camera |
| Playing | **Esc** | pause |
| Playing | **M** | toggle AZS Spell Meter (Expanded / Mini / Hidden) |
| Playing | click **DPS / DMG / KILLS** | cycle meter sorting |
| Playing | click **[M]** meter button | cycle meter view state |
| Playing | — | abilities cast themselves (no aim) |
| Level up | **1 / 2 / 3** (or click a card) | pick an upgrade |
| Level up | **R** (or click **[R] Reroll**) | reroll card draft (default 2/run) |
| Level up | **X** (or click **[X] Skip**) | skip card draft, gain +50 XP (default 1/run) |
| Level up | **B** (or click **[B] Banish**) | banish card from run (default 2/run) |
| Paused | **Esc** | resume |
| Game over | **Enter** (or **Play again**) | back to the menu |
| Any | minimap **+ / −** / minimize | minimap zoom / collapse |

## Gamepad / Controller Controls (Xbox / PS / Steam Deck)

| Context | Gamepad Input | Action |
|---|---|---|
| Playing | **Left Stick** / **D-Pad** | Move hero |
| Playing | **Right Stick** | Twin-stick aiming (directs spells & mobility) |
| Playing | **Right Trigger (RT / R2)** / **B** | Dash (12 yd surge, 0.25s i-frame, 3s cd) |
| Playing | **A / Cross** | Jump |
| Playing | **Left Trigger (LT / L2)** / **Y / North** | Class Ultimate (when meter reaches 100%) |
| Playing | **Left Trigger (LT / L2)** / **X** | Class mobility spell (Blink, Charge...) |
| Playing | **Back / Select** | Toggle Spell Meter |
| Playing | **Start** | Pause / Menu |
| Level up | **X / Square** | Pick Card 1 |
| Level up | **A / Cross** | Pick Card 2 |
| Level up | **B / Circle** | Pick Card 3 |
| Level up | **Y / Triangle** | Banish card |
| Level up | **Right Bumper (RB) / Select** | Reroll draft |
| Level up | **Left Bumper (LB) / Start** | Skip draft (+50 XP) |
| Menu / Paused | **Start** / **A** | Confirm / Enter World / Resume |

The camera follows the hero, locked top-down by default (laptop-friendly). **C** unlocks it so a
mouse drag swings and tilts it; **C** again snaps it back. In the menu it slowly orbits the
preview hero. Your race, gender, class and zone are remembered across reloads.
